# MDINotepad - MFC多文档记事本

一个基于MFC框架开发的多文档界面(MDI)记事本应用程序，具有丰富的文本编辑功能和自定义文件格式支持。

## 🚀 功能特性

### 📝 核心编辑功能
- **多文档界面**：支持同时打开和编辑多个文档
- **基本文本编辑**：支持插入、删除、复制、粘贴等基本操作
- **撤销/重做**：完整的编辑操作历史记录支持
- **查找与替换**：支持文本查找、替换和全部替换功能
- **全选与删除**：支持选择全部文本和清空文档

### 🎨 界面特性
- **暗色主题**：支持亮色/暗色主题切换
- **行号显示**：可开关的行号显示功能
- **自定义字体**：使用Consolas等宽字体
- **滚动支持**：水平和垂直滚动条
- **光标定位**：精确的光标位置计算和显示

### 📁 文件格式支持
- **标准文本文件**：支持.txt格式文件
- **自定义加密格式**：支持.mynote加密文件格式
- **文件关联**：注册.mynote文件扩展名关联
- **UTF-8编码**：支持Unicode文本编码

### 🔒 加密功能
- **AES-CBC加密**：.mynote文件使用AES-CBC模式加密
- **SHA-1摘要**：文件完整性验证
- **学生信息嵌入**：在文件头中包含学生标识信息

## 📋 系统要求

- **开发环境**：Microsoft Visual Studio 2019或更高版本
- **框架**：MFC (Microsoft Foundation Classes)
- **平台**：Windows 7/8/10/11
- **编译器**：支持C++11的MSVC编译器

## 🏗️ 构建说明

### 1. 环境配置
1. 确保已安装Visual Studio和C++ MFC组件
2. 克隆或下载项目源码
3. 打开`MDINotepad.sln`解决方案文件

### 2. 构建步骤
1. 选择构建配置（Debug/Release）
2. 生成解决方案（Ctrl+Shift+B）
3. 确保所有依赖项正确链接

### 3. 运行测试
1. 按F5启动调试
2. 程序将自动注册.mynote文件关联
3. 测试各项功能是否正常工作

## 🎯 使用说明

### 基本操作
1. **新建文档**：文件 → 新建 或 Ctrl+N
2. **打开文件**：文件 → 打开 或 Ctrl+O
3. **保存文件**：文件 → 保存 或 Ctrl+S
4. **另存为**：文件 → 另存为（可选择.txt或.mynote格式）

### 编辑功能
1. **查找文本**：编辑 → 查找 或 Ctrl+F
2. **替换文本**：编辑 → 替换 或 Ctrl+H
3. **撤销操作**：编辑 → 撤销 或 Ctrl+Z
4. **重做操作**：编辑 → 重做 或 Ctrl+Y
5. **删除全部**：编辑 → 删除全部

### 视图设置
1. **切换主题**：视图 → 暗色主题
2. **行号显示**：视图 → 行号
3. **字体调整**：通过修改源码中的字体设置

### 文件格式
- **.txt文件**：标准文本文件，无加密
- **.mynote文件**：自定义加密格式，包含：
  - 文件头标识
  - 学生信息（学号）
  - 加密的文档内容
  - SHA-1摘要验证

📝 注意事项
编码问题：确保打开的文件使用UTF-8编码，否则可能出现乱码

大文件处理：当前版本未优化超大文件处理，建议文件大小不超过10MB

加密安全性：演示版本使用简化的加密实现，实际使用请加强加密算法

撤销限制：撤销栈有内存限制，大量编辑操作可能丢失早期历史

中文字符处理：某些中文字符的宽度计算可能不准确
